# Spacebyte

用于模型下载、数据准备、微调、评估和推理的项目仓库。

当前先建立与具体模型和训练框架解耦的基础结构；模型确定后，再补充依赖、配置和训练入口。

## 目录结构

```text
configs/       训练和推理配置
data/          本地数据（默认不提交）
docs/          项目文档
models/        本地模型权重（默认不提交）
outputs/       日志、检查点和评估结果（默认不提交）
scripts/       下载、预处理、训练和评估脚本
src/spacebyte/ Python 源代码
tests/         自动化测试
```

## 开始使用

模型、数据格式和微调方案确定后，在此补充环境安装及训练命令。

## Git 安全约定

数据集、模型权重、训练产物、环境变量和访问令牌不得提交到仓库。需要共享的小型示例数据应先脱敏，并存放在单独的样例目录中。
